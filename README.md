# astrbot_plugin_force_silent

強制靜默插件，支援硬靜默與協同模式，適合讓 Bot 在指定群中只保留必要管理能力。

## 指令

- `/強制靜默 狀態`
- `/強制靜默 統計`
- `/強制靜默 開啟`
- `/強制靜默 關閉`
- `/強制靜默 添加群 <群號>`
- `/強制靜默 刪除群 <群號>`
- `/強制靜默 協同開啟`
- `/強制靜默 協同關閉`

英文相容：`/force_silent ...`

## 模式說明

- 協同模式（預設）：不 `stop_event`，適合與採集、匯出、統計類插件並存
- 硬靜默模式：命中群後直接 `stop_event`，最大化阻止後續回覆流程
- 管理指令放行：插件管理員仍可在靜默群內使用 `/強制靜默` 或 `/force_silent` 調整設定，避免鎖死
